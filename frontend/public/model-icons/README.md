# Model icons

Provider logos from [LobeHub Icons](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg` 1.95.1, MIT License, Copyright (c) LobeHub).
The logos are trademarks of their respective owners and are used only to identify their models.

The mapping from OpenRouter model ids to these files lives in `src/lib/modelIcons.ts`.
Files without `-color` are single-colour (`fill="currentColor"`) and are drawn as a CSS mask in the
current text colour.
